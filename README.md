# AWS Community Day Bengaluru and regular monthly meetup slides

This repository collects presentation slides shared by speakers at AWS Community Day Bengaluru meetups. Each event has its own folder containing the slide decks and, where available, an event-specific README.

## Contributing slides

Add speaker-provided slide decks to the folder for the corresponding meetup. For a new meetup, create a clearly named event folder and include a README listing and briefly describing its decks.
